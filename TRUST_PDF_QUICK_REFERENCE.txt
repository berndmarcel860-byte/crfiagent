HOW TO USE
================================================================================

STEP 1: Generate PDFs on production server
  
  $ cd /var/www/your-site/app/admin/trust-pdfs
  $ php generate_all_trust_pdfs.php
  
  Output: documents/trust/BaFin_Verification_*.pdf (+ 3 more)

STEP 2: Review PDFs
  
  Check:
  ✓ BaFin reference number correct
  ✓ Company name and address accurate
  ✓ Contact information current
  ✓ German text displays properly

STEP 3: Integrate with welcome email
  
  Update admin/admin_ajax/add_user.php:
  
  ```php
  // Generate PDFs
  exec("php " . __DIR__ . "/../trust-pdfs/generate_all_trust_pdfs.php");
  
  // Get PDF files
  $pdfs = [
      glob($trustDir . 'BaFin_Verification_*.pdf')[0],
      glob($trustDir . 'Service_Agreement_*.pdf')[0],
      glob($trustDir . 'Company_Information_*.pdf')[0],
      glob($trustDir . 'Onboarding_Guide_*.pdf')[0]
  ];
  
  // Send with attachments
  $emailHelper->sendTemplateEmailWithAttachments(
      'user_registration', 
      $userId, 
      $customVars, 
      array_filter($pdfs)
  );
  ```

STEP 4: Test and deploy
  
  Test with sample user, verify PDFs received, deploy to production.
